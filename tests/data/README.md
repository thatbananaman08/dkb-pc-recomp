# Instruction corpus

`pokopia-corpus.json.gz` contains the unmodified `recomp/oracle/difftest/corpus.json` from
[switch2-recomp](https://github.com/drakolordx7/switch2-recomp) at commit
`5339bf85b05e84c34a7f18d8a43db1de1f1692b2`, compressed to fit the repository's file-size limit. It was generated by
that project's `recomp/oracle/difftest/gen_corpus.py`, which carries `SPDX-License-Identifier: GPL-3.0-or-later`;
the project lists its recomp component as GPL-3.0-or-later. The data is generated from instruction encodings and
contains no game files. SHA-256 of the uncompressed JSON:

`6b9b43ebdbbb85a302db51417fb09c822da56ce97391eae068eed541ab6381cf`

The file contains instruction shapes and words, not saved machine states. It targets Cortex-A57 plus LSE and
LRCPC instructions; its recorded exclusions include later AArch64 extensions. See `docs/building.md` for the portion
the DKB runner executes and the limitations of its coverage report.
